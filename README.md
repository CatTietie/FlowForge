# FlowForge

低代码表单与流程引擎，让业务人员通过拖拽即可设计表单和审批流程，系统自动生成可执行的前端页面并驱动流程状态机，无需开发介入即可完成请假、采购、入职等企业内部流转场景的全生命周期管理。

## 功能概览

- **表单设计器**：可视化拖拽布局，支持文本框、下拉、日期、数字等十余种控件，配置校验规则与数据联动，即时预览。
- **流程设计器**：基于节点和连线的流程图编辑，支持串签、会签、条件分支，所见即所得定义审批路径。
- **动态渲染引擎**：根据表单 Schema 自动生成填写页面，校验规则与联动逻辑自动生效。
- **流程状态机**：严格解析流程定义 JSON，驱动流程流转、会签决策、退回和超时处理，完整记录审批历史。
- **版本管理**：表单与流程定义每次修改自动生成新版本，历史版本可回溯恢复。
- **权限控制**：设计权限与运行权限分离，支持按角色分配发起和审批权限。

## 技术栈

| 层级 | 技术 |
|------|------|
| 表单设计器前端 | React + 拖拽库 |
| 流程设计器前端 | React + react-flow |
| 渲染引擎后端 | Python FastAPI |
| 流程引擎 | Python 状态机 |
| 数据库 | PostgreSQL |
| 版本管理 | 数据库级版本记录 |

## 快速开始

```bash
# 后端
cd server
pip install -r requirements.txt
uvicorn main:app --reload

# 前端设计器
cd designer
npm install
npm run dev
访问 http://localhost:5173 进入设计器，创建表单和流程后，填写端页面由渲染引擎动态生成。
